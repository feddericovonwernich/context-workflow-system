# Phase 3: Aggregate Results

**Purpose**: Aggregate all task results and generate a comprehensive summary report.

## Prerequisites
- Phase 2 (task iteration) has completed
- task-results.json exists (generated by orchestrator)
- Runtime parameters include TASKS_COMPLETED, TASKS_FAILED, TASKS_BLOCKED

## Tasks for Todo List
1. Load aggregated task results
2. Analyze success/failure patterns
3. Generate summary statistics
4. Create human-readable report
5. Display final summary

## Parameters Used
- `OUTPUT_DIR`: Base directory for all files
- `TASK_INDEX_PATH`: Path to task index
- `TASKS_COMPLETED`: Count of successful tasks
- `TASKS_FAILED`: Count of failed tasks
- `TASKS_BLOCKED`: Count of blocked tasks

## Process

### Step 1: Load Aggregated Results
Read the aggregated results from the workflow run directory:
- The orchestrator generates `task-results.json` after task iteration completes
- This file contains all individual task results in one place
- Also check runtime parameters for task counts

### Step 2: Analyze Results
For each task result:
- Count successes, failures, and blocked tasks
- Identify any patterns in failures
- Calculate total processing time
- List dependencies that were resolved

### Step 3: Generate Summary Statistics
Calculate:
- Success rate: (completed / total) × 100%
- Average processing time per task
- Batch completion times
- Dependency resolution effectiveness

### Step 4: Create Summary Report
Generate `$OUTPUT_DIR/summary-report.md` with:

```markdown
# Task Iteration Example - Summary Report

## Overview
- **Total Tasks**: {total_tasks}
- **Completed**: {TASKS_COMPLETED} ({success_rate}%)
- **Failed**: {TASKS_FAILED}
- **Blocked**: {TASKS_BLOCKED}

## Task Results

### Batch 1
| Task ID | Status | Processing Time | Notes |
|---------|--------|-----------------|-------|
| TASK-1  | ✓ Success | 2.3s | - |
| TASK-2  | ✓ Success | 1.8s | - |
| TASK-4  | ✓ Success | 2.1s | - |

### Batch 2
| Task ID | Status | Processing Time | Notes |
|---------|--------|-----------------|-------|
| TASK-3  | ✓ Success | 2.5s | Dependency: TASK-1 |
| TASK-5  | ✓ Success | 2.2s | Dependency: TASK-2 |

## Performance Metrics
- **Total Processing Time**: {total_time}s
- **Average Time per Task**: {avg_time}s
- **Fastest Task**: {fastest_task} ({time}s)
- **Slowest Task**: {slowest_task} ({time}s)

## Dependency Resolution
- **Total Dependencies**: {dep_count}
- **Successfully Resolved**: {resolved_count}
- **Blocked**: {blocked_count}

## Task Iteration Feature Demonstration
✓ Each task executed in isolated agent context
✓ Dependency tracking worked correctly
✓ Result aggregation successful
✓ Resumption support enabled (can restart from failures)

## Conclusion
{summary_text}
```

### Step 5: Display Summary
Output key metrics to the console:
```
═══════════════════════════════════════════
Task Iteration Example - Results
═══════════════════════════════════════════
Completed: {TASKS_COMPLETED}/{total_tasks}
Failed: {TASKS_FAILED}
Blocked: {TASKS_BLOCKED}
Success Rate: {success_rate}%
═══════════════════════════════════════════
```

## Outputs
- `$OUTPUT_DIR/summary-report.md` - Comprehensive summary report

## Error Handling
- If task-results.json not found, check if phase 2 completed
- If runtime parameters missing, attempt to calculate from result files
- Report any incomplete or malformed result files
- Generate partial report if some data is unavailable
